# SchoolHub — โรงเรียนเทพศาลาประชาสรรค์

เว็บแอปสำหรับจัดการนักเรียน ห้องเรียน และชุมนุม โดยใช้ **Cloudflare Pages Functions + D1** และ GitHub เป็นแหล่งเก็บ Source Code

## รุ่นปัจจุบัน: v1.4.0

- Super Admin / Admin / ครู ใช้บัญชีแยกและตรวจสิทธิ์ฝั่ง API
- นักเรียน ชุมนุม การเปลี่ยนชุมนุม ประวัติการแก้ไข และ Soft Delete
- Import XLSX/CSV (ทีละหนึ่งห้อง สูงสุด 120 แถว) พร้อม Preview, ตรวจซ้ำ, Full Sync และประวัติการนำเข้า
- **ใหม่:** ผู้ดูแลตั้งสิทธิ์ Import Excel ของครูรายคนได้ และแยกสิทธิ์ Full Sync; ครูนำเข้าได้เฉพาะห้องที่มอบหมาย

## ติดตั้ง/อัปเดต

อ่าน `INSTALL_TH_v1.4.md` ในไฟล์อัปเดต ZIP

**สำคัญ:** อย่าฝังข้อมูลนักเรียนจริงหรือรหัสผ่านไว้ในไฟล์ HTML, GitHub หรือ Source Code สาธารณะ และทดสอบบน Cloudflare Pages Staging ก่อนทุกครั้ง

## โครงสร้าง

- `public/` หน้าเว็บไซต์, ภาพและเทมเพลต
- `functions/api/[[path]].js` Pages Functions API
- `migrations/` SQL สำหรับ D1 (รัน Migration ตามลำดับและครั้งเดียว)
- `tests/` ชุดทดสอบในเครื่อง
- `scripts/build.mjs` เก็บหน้า Demo เดิมจาก `index.html` ที่ราก GitHub

### คำสั่งตรวจสอบ

```bash
npm run check
npm test
```

ข้อจำกัด: รุ่นนี้ยังไม่รองรับครูที่ปรึกษาชุมนุมนำเข้า **สมาชิกชุมนุม** ผ่าน Excel โดยตรง; การนำเข้าข้างต้นเป็นของครูประจำชั้นที่มีสิทธิ์เท่านั้น
